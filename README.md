# QH｜千幻桌面便笺

一款面向 Windows 的透明桌面记事本与任务册，基于 Electron 构建。

## 功能

- 透明、无边框桌面展示
- 记事本与任务册
- 自定义分类和标签颜色
- 任务严重程度、顺序、开始时间和截止时间
- 背景图片、透明度和文字颜色
- 系统托盘与开机自动启动
- 自由缩放、固定常用比例或自定义比例
- 本地自动保存

## 本地运行

```powershell
npm install
npm start
```

## 检查与构建

```powershell
npm run check
npm run build:exe
```

Windows 安装包请前往仓库的 Releases 页面下载。
