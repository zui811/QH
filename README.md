# QH｜千幻桌面便笺

面向 Windows 的透明桌面记事本、任务册与本地剪贴板历史工具，基于 Electron 构建。

## 功能

- 透明、无边框桌面展示，支持背景图片、文字颜色与完全透明模式
- 分类记事本，内容自动保存在本机
- 任务册：严重程度、顺序、开始时间、截止时间、备注、完成状态
- 自定义分类名称和标签颜色
- 自由缩放、常用固定比例与自定义比例
- 系统托盘、窗口置顶和开机启动
- 本地剪贴板历史：文本、富文本、图片和多文件路径
- 剪贴板搜索、去重、收藏、纯文本粘贴、数量/过期设置与暂停记录
- 单实例运行、损坏数据自愈、剪贴板容量保护与保存失败提示

## 剪贴板快捷键

- `Ctrl+Shift+V`：打开剪贴板历史
- 面板内 `1`～`9`：粘贴对应记录
- `Alt+1`～`Alt+9`：直接快速粘贴
- `↑` / `↓`：移动选择
- `Enter`：粘贴，`Shift+Enter`：纯文本粘贴
- `Esc`：隐藏窗口

快捷键被其他程序占用时，剪贴板设置中会显示状态。自动粘贴会尝试恢复原窗口，并在粘贴完成后恢复此前的系统剪贴板内容。

## 隐私与数据

- 笔记、任务和设置只保存在当前电脑的 Electron 用户数据目录。
- 剪贴板历史默认不上传云端，也不会写入安装包或分享包。
- 默认排除 1Password、Bitwarden、KeePass、KeePassXC，可自行添加排除程序。
- 单条剪贴板内容最大 20 MB，历史总容量最大 100 MB。
- 可关闭“重启后保留历史”，或随时暂停、删除和清空记录。
- 密码和敏感资料复制前，仍建议主动暂停剪贴板记录。

## 本地运行

```powershell
npm install
npm start
```

## 检查与构建

```powershell
npm run check
npm run build:exe
```

构建流程会生成 Windows NSIS 安装程序和分享 ZIP，并自动校验 ZIP 内安装程序的 SHA-256。`dist` 目录只保留最近两个版本。

Windows 安装包请前往仓库的 Releases 页面下载。
