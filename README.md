# QH｜千幻桌面便笺

一款面向 Windows 的透明桌面记事本、任务册与本地剪贴板历史工具，基于 Electron 构建。

## 功能

- 透明、无边框桌面展示
- 记事本与任务册
- 自定义分类和标签颜色
- 任务严重程度、顺序、开始时间和截止时间
- 背景图片、透明度和文字颜色
- 系统托盘与开机自动启动
- 自由缩放、固定常用比例或自定义比例
- 本地自动保存
- 剪贴板文字、富文本、图片与文件路径历史
- `Ctrl+Shift+V` 打开历史，面板内 `1～9` 粘贴，`Alt+1～9` 直接粘贴
- 搜索、去重、收藏、纯文本粘贴、删除确认与清空未收藏项
- 可暂停记录、设置数量与过期时间、选择是否跨重启保留
- 默认排除常见密码管理器，也可自定义排除程序

## 剪贴板隐私

剪贴板历史默认只保存在当前电脑的应用数据目录，不上传云端，也不会写入安装包或分享包。可在剪贴板设置中关闭“重启后保留历史”，或随时暂停、删除与清空记录。

## 本地运行

```powershell
npm install
npm start
```

## 检查与构建

```powershell
npm run check
npm run build:exe
```

Windows 安装包请前往仓库的 Releases 页面下载。
